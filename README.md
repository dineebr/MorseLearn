# ⚡ MorseLearn

> ⚡ An intuitive web application designed to learn Morse code with real-time sound, complete lessons (A–Z and 0–9), and interactive practical exercises.

---

### 👨‍💻 Authorship & Credits

This project was created and developed by **[dineebr](https://github.com/dineebr)**.

---

### ✨ Features

- 📖 **Complete Learning (A–Z and 0–9):** Structured and educational presentation of all letters and numbers before starting practice exercises.
- 🔊 **Web Audio API:** Real audio synthesis for dots (`.`) and dashes (`-`) without needing external sound files.
- 🎯 **Practical Exercises:** Multiple choice, reverse translation, and Morse typing to test and solidify your knowledge.
- 🔄 **Interactive Translator:** Converts typed text into Morse code with simultaneous audio playback.
- 📱 **Responsive Design:** Clean, modern interface optimized for both desktop and mobile devices.

---

### 🛠️ Technologies Used

- **HTML5**
- **Tailwind CSS**
- **JavaScript (ES6+)**
- **Web Audio API**
